# Grafana Loki Monitoring Setup

Date: August 11, 2026

1. Create Docker network

The monitoring containers were placed on a dedicated Docker network:

docker network create monitoring

2. Start Loki

Loki was started using the official Grafana Loki Docker image:

docker run -d 
--name loki 
--network monitoring 
-p 3100:3100 
grafana/loki:latest

3. Verify Loki

Check that the Loki container is running:

docker ps

Check the Loki readiness endpoint:

curl http://localhost:3100/ready

Expected response:

ready

4. Log forwarding

Grafana Alloy was used to collect Docker container logs and forward them to Loki.

Alloy was configured to discover Docker container log files and send them to the local Loki instance.

Alloy logs confirmed that Docker log files were being discovered and tailed.

Example:

start tailing file
component_id=loki.source.file.docker_logs

5. View Loki labels

The following command can be used to confirm that Loki is receiving log metadata:

curl "http://localhost:3100/loki/api/v1/labels"

Example response:

{"status":"success","data":["filename","job","service_name"]}

6. Useful commands

Check Loki:

docker ps

View Loki logs:

docker logs loki

Check Loki readiness:

curl http://localhost:3100/ready

View Alloy logs:

docker logs alloy

Check available Loki labels:

curl "http://localhost:3100/loki/api/v1/labels"

7. Result

Loki was successfully started locally using Docker.

Grafana Alloy was configured to collect Docker container logs and forward them to Loki.

The Loki readiness endpoint returned:

ready

This confirms that Loki was running and ready to receive log data.
